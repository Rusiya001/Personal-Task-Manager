# Personal Task Manager

An individual coursework project for 5COSC026C Advanced Client-Side
Development, built using React and TypeScript.

The application will help users create, organise and track personal tasks.

## Planned Features

- Create, view, edit and delete tasks.
- Set task descriptions, due dates, priorities and statuses.
- Simulated login, protected routes and logout.
- Form validation and clear user feedback.
- Responsive and accessible layouts.
- Loading, error and empty states.

## Planned Technologies

- React and TypeScript
- Vite
- React Router
- Zustand
- CSS
- Vitest and React Testing Library
- GitHub Pages

## Data

The application will fetch at least ten initial task records from a
JSON file in the public directory.

Task changes will be managed in client-side state. The persistence
approach and JSON structure will be documented during implementation.

Authentication will be simulated. No real credentials will be used.
